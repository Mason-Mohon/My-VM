To run something:
`gcc -Wall -Wextra -std=c11 -o [compiled name] src/[file].c` 

Then: `./[compiled name]` 

`0MM0OOOO DDDDAAAA 0000BBBB 00000000`

- M = Mode
- O = Opcode
- D = Destination
- A = Operand A
- B = Operand B
